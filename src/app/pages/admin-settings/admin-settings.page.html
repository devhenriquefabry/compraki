Frete grátis por valor

Todo produto com preço a partir do valor mínimo sai com frete grátis — e o selo aparece no produto.

@if (config().freeShipping.enabled) { Ligado: produtos a partir de {{ formatBRL(config().freeShipping.minValue) }} têm frete grátis. } @else { Desligado. Só vale o frete grátis que o próprio vendedor oferece no anúncio. }

No checkout, o pedido sai sem frete quando todos os itens têm frete grátis. A etiqueta continua sendo comprada pelo Melhor Envio — o custo real fica registrado no pedido (aba Pedidos).
